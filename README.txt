EMMANUEL OLUSOLA — STUDENT PORTFOLIO
===================================

HOW TO OPEN
1. Extract this ZIP file.
2. Open the extracted folder "Emmanuel_Olusola_Portfolio" in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension (recommended).
4. Use the navigation menu to visit About Me, Projects, Academic Planner and Contact.

PROJECT FILES
- index.html       Homepage
- about.html       Education, aspirations, skills and interests
- projects.html    Three sample projects and multimedia
- planner.html     Interactive academic task planner
- contact.html    Contact form with JavaScript validation
- css/style.css   External responsive stylesheet
- js/script.js    Navigation, planner and form validation
- images/         Your uploaded portrait and project preview images
- media/          Sample video and audio (if generated on this system)

NOTES
- The academic planner saves tasks in the browser's localStorage.
- The contact form validates entries but does not send messages to an email server.
- Project links are internal demonstration links; replace them with your own GitHub project links when available.
- The sample multimedia files are demonstrations. Replace them with your own voice/video if required by your lecturer.
- Some fonts are loaded from Google Fonts, so an internet connection is needed for those fonts. The site remains usable offline with fallback fonts.

BEFORE SUBMISSION
1. Check every page in a browser.
2. Add your real GitHub repository URL to the project cards if available.
3. Upload the project folder to GitHub.
4. Deploy using GitHub Pages or another static hosting service.
5. Submit both the hosted website URL and GitHub repository URL to MIVA.
